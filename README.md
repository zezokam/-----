# البحث في مبادئ المحكمة العليا العمانية

محرك بحث ذكي للعثور على مبادئ المحكمة العليا العمانية حسب نوع الدعوى والموضوع القانوني، مع إمكانية البحث في الإنترنت عند عدم وجود نتائج كافية محلياً.

## المميزات

### 🔍 البحث الذكي
- بحث متقدم في قاعدة بيانات تحتوي على **6766 مبدأ قضائي**
- فهرسة ذكية للكلمات المفتاحية (أكثر من 12000 كلمة)
- حساب درجة الصلة لكل نتيجة
- اقتراحات البحث التلقائية

### 📊 قاعدة البيانات الشاملة
- **مبادئ جزائية**: 3417 مبدأ
- **مبادئ مدنية**: 2241 مبدأ  
- **مبادئ شرعية**: 227 مبدأ
- **مبادئ أخرى**: 881 مبدأ

### 🌐 البحث الإلكتروني
- البحث في موقع qanoon.om (المصدر الرسمي العماني)
- البحث في مواقع المحاكم العربية (مصر، الإمارات، الكويت، السعودية، قطر)
- البحث في المواقع القانونية العامة
- عرض النتائج مصنفة حسب المصدر والبلد

### 🎨 التصميم
- تصميم مطابق تماماً لموقع alkamali.uk
- واجهة عربية احترافية
- متجاوب مع جميع الأجهزة
- ألوان وخطوط متناسقة

## التقنيات المستخدمة

### الواجهة الأمامية (Frontend)
- **HTML5** مع دعم كامل للعربية
- **CSS3** مع متغيرات مخصصة ونظام ألوان متقدم
- **JavaScript ES6+** مع Fetch API
- **Font Awesome** للأيقونات
- **Google Fonts** (Noto Sans Arabic)

### الواجهة الخلفية (Backend)
- **Python 3.11** مع Flask
- **Flask-CORS** للسماح بالطلبات من مصادر مختلفة
- **BeautifulSoup4** لتحليل صفحات الويب
- **Requests** للبحث الإلكتروني
- **JSON** لتخزين قاعدة البيانات

### معالجة البيانات
- **python-docx** لقراءة ملفات Word الحديثة
- **antiword** و **catdoc** لملفات Word القديمة
- **Regular Expressions** للبحث والفهرسة
- **Unicode** للنصوص العربية

## التشغيل السريع

### 1. تثبيت المتطلبات
```bash
# تثبيت Python dependencies
pip install -r requirements.txt

# تثبيت أدوات معالجة ملفات Word (Ubuntu/Debian)
sudo apt update
sudo apt install -y antiword catdoc
```

### 2. تشغيل الخادم
```bash
python app.py
```

### 3. فتح المتصفح
```
http://localhost:5000
```

## API المتاحة

### البحث في المبادئ
```http
POST /api/search
Content-Type: application/json

{
    "query": "سرقة ليلاً",
    "court_type": "جزائي",
    "max_results": 20,
    "include_online": true
}
```

### الحصول على اقتراحات البحث
```http
GET /api/suggestions?q=سرقة
```

### إحصائيات قاعدة البيانات
```http
GET /api/stats
```

## أمثلة البحث

### البحث الأساسي
- `سرقة ليلاً` - للبحث عن مبادئ السرقة الليلية
- `انتهاك حرمة مسكن` - لمبادئ انتهاك حرمة المساكن
- `الشفعة` - لمبادئ حق الشفعة
- `نفقة الأطفال` - لمبادئ نفقة الأطفال

### البحث المتقدم
- استخدام فلاتر نوع المحكمة (جزائي، مدني، شرعي، إداري)
- تحديد عدد النتائج (10، 20، 50)
- تفعيل/إلغاء البحث الإلكتروني
